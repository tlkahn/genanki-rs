### 3.1 Atomic publish sketch (implementation target)

```rust
pub(crate) fn write_to_file_impl(
    decks: &[crate::Deck],
    media_files: &[PathBuf],
    path: impl AsRef<Path>,
    timestamp_secs: f64,
) -> Result<()> {
    let dest = path.as_ref();
    let media_plan = plan_media(media_files)?;

    // 1. collection.anki2 in process temp (unchanged idea)
    let db_tmp = tempfile::NamedTempFile::new()?;
    let conn = rusqlite::Connection::open(db_tmp.path())?;
    write_db(&conn, decks, timestamp_secs)?;
    conn.close().map_err(|(_, e)| e)?;

    // 2. Zip into a temp file in the destination directory
    let parent = dest_parent(dest); // "." if bare filename
    let zip_tmp = tempfile::NamedTempFile::new_in(parent)?;
    let options = zip_file_options(timestamp_secs); // pinned mtime
    let mut zip = zip::ZipWriter::new(zip_tmp);
    // ... collection.anki2, media JSON, blobs ...
    let zip_tmp = zip.finish()?;

    // 3. Publish only on full success
    zip_tmp.persist(dest).map_err(|e| e.error)?;
    Ok(())
}
```

`NamedTempFile` implements `Write + Seek`, so `ZipWriter::new(zip_tmp)` +
`finish() -> NamedTempFile` + `persist` is the intended ownership chain.
Map `PathPersistError` via its `error: io::Error` into `Error::Io`.

### 3.2 Zip mtime helper sketch

```rust
fn zip_mtime(timestamp_secs: f64) -> zip::DateTime {
    // 1. secs = timestamp_secs as i64 (trunc toward zero; match mod cast style)
    // 2. clamp to [1980-01-01 00:00:00 UTC, 2107-12-31 23:59:58 UTC]
    // 3. civil UTC breakdown without new deps (small private fn or tables)
    // 4. DateTime::from_date_and_time(y, m, d, h, min, sec).unwrap_or(default)
    //    DOS seconds are even; mask `sec & !1` if required by from_date_and_time
}

fn zip_file_options(timestamp_secs: f64) -> zip::write::SimpleFileOptions {
    zip::write::SimpleFileOptions::default().last_modified_time(zip_mtime(timestamp_secs))
}
```

If a full UTC breakdown is painfully long for this pass, an acceptable
fallback locked by tests is: **always pin to 1980-01-01 00:00:00** for every
entry (still byte-stable; rustdoc must then say zip metadata is fixed, not
derived). Prefer derived-from-`timestamp_secs` if the helper stays < ~40 lines;
otherwise use the constant epoch and document it. **Decision at implement
time under the byte-identity test** - both satisfy finding 2.

fn fixed_timestamp_writes_are_byte_identical() {
    let mut deck = Deck::new(123456, "foodeck");
    deck.add_note(Note::new(simple_model(), ["a", "b"]).unwrap());
    let pkg = Package::new(deck);

}
